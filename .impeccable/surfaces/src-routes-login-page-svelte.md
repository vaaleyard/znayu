# Operator login

## Scope and mode

- Route: `/login`
- Visitor mode: interface-only operator sign-in prototype.
- Audience: operators who manage monitors, maintenance windows, and public status communication.
- Job: recognize the private console, enter credentials, and understand that authentication is not connected yet.

## Chosen direction

The login surface extends Znayu's operational register into a quiet, centered access record. It uses the existing blue-black field, emerald state signal, system typography, 12px register surface, 5px controls, and a direct return path to the public status page.

## Boundaries

- No authentication, persistence, password recovery, validation, or backend behavior is implemented.
- The prototype state is disclosed beside the form rather than implied as production capability.
- Copy remains in English to match the public status page.
